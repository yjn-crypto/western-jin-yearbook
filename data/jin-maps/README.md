# 西晋289年与308年地图数据

本目录保存从既有完整成果生成的网页用GeoJSON：289年1741个要素、308年1750个要素。网页几何经过0.003度简化并保留六位小数；完整成果中的边界和坐标未因此改动。研究记录在 `../jin-fief-research/`。

289年为年末封国研究断面。308年为原图工作断年，名称组合支持308—310年，表达名义建置与封国关系，不代表实际军事控制。秦州等建置存在地图与年表来源分歧，保留双方记录；未唯一对应的实体不强接正文。

CHGIS同年治所及郡面优先，缺失处使用用户提供的地图矢量。原图文字锚点不是治所；县级封爵旁注不等同整县封国。研究推定与不确定区域保留相应标记。源CHGIS郡面之间少量重叠原样保留，不据此臆造飞地或裁改边界。

## 文字与边界显示

低于300%显示州名；300%至700%显示州、郡国范围名；超过700%增加县名和治所小字。郡范围文字优先参考 `../jin-map-label-anchors.js` 中原图确认的位置；原位置不在年度郡面内时改用面内位置。狭窄郡面的范围名必要时缩小，仍须完整留在界内并避开其他名称。文字摆位不改变治所坐标或行政边界。原始县治层为旧版绘图设置的隐藏文字标记不再屏蔽网页的县级标签。

州界使用较粗深色线，国界保留棕线和原封国填色，国中郡界保持淡化。斜体、※沿用原成果的 `inferred` 等推定标记；斜线填充表示范围或封国成员归属推定，两者并非同一含义。原生成程序对五等爵封国使用了较宽的统一推定标记，因此不能据斜体断言该封国的存在、封君或整个边界均有史料争议。本次显示修正不重新裁定这些研究结论。
