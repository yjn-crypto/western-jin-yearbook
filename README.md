# 漢魏六朝年末州郡縣表

目前可用朝代：

- 西晉（266—316）
- 南陳（558—588）

西漢、東漢、曹魏、東晉、劉宋、蕭齊、蕭梁已預留切換入口，尚未加入資料。

## 本版新增

1. 新增朝代切換器。
2. 西晉採金德主題，南陳採土德主題；紙張、字體、表格與註釋樣式維持原有風格。
3. 南陳逐年年末州—郡—縣表，保留原書排列次序。
4. 南陳州郡縣後列「未定位／疑似虛封封爵」，再列後梁、王琳政區；無法附著並不一律等同虛封，二王後等制度性封國即使暫無可附著的政區，也會保留並註明其非虛封性質。
5. 後梁、王琳政區只在其存續年份顯示。
6. 南陳宗室王國在郡級政區旁標示王號、姓名，不計算元年、二年。
7. 郡公附於郡級政區；開國公侯伯子男附於縣級政區，分別標作公國、侯國、伯國、子國、男國。
8. 無法唯一匹配本年南陳實際郡縣的封爵，原則上列入「未定位／疑似虛封封爵」；是否屬虛封仍以個別考據為準。汝南、建安、鍾陵等已有人工考據定位者，以人工定位優先。
9. 封爵承襲加入考據顯示規則：史料明載的襲封時間優先；無明文而前任卒年、親屬關係可確者，原則上在卒後第三年記新封君，中間兩年記世子服喪；最後可確年份後資料不足者以斜體標示存疑。
10. 南陳558—588年均可顯示地形行政圖：558—587年共用地形底圖並按年份動態繪製行政與封國向量層；588年保留人工覆核的9600×8256超高清PNG。地圖與州郡縣文字可雙向定位，588年完整行政、封國及CHGIS圖層審計資料可下載為CSV。
11. 南陳僑郡縣依本書第十編「僑州郡縣考表」補充。陳代不另列無實土僑州，州級名稱與原有統屬保持不變；僑郡、僑縣以下劃線標示。表中梁○、陳△用於判讀梁、陳欄資料。
12. 僑置標記優先於「正文未標年代」的淡色規則：同一縣若正文無明確年限而侨置表可確認其侨縣性質，改為正常字色＋下劃線。點擊侨置註釋可查看「原屬」及考表依據。
13. 南陳年份顯示改用《魏晉南北朝方鎮年表新編》的「年號＋干支＋（公元年份）」格式，如「太建十四年壬寅（582）」「後主至德元年癸卯（583）」。
14. 新增南陳方鎮長官資料層。各州在主表內以「都督/刺史」逐人分行列出本年年表所見人物、時間與完整官銜；州名及「都督/刺史」標題均可點擊查看王爵、遷轉及原書考證；無資料的州不顯示此區塊。
15. 方鎮年表有長官條目、但本年政區表沒有相應州者，列於南陳州郡縣之後、未定位／疑似虛封封爵之前的「方鎮表另見之州」，不據方鎮官銜直接反推實際政區。

## 資料來源

### 行政區劃

- 《中國行政區劃通史·三國兩晉南朝卷（上）》西晉州郡縣沿革。
- 《中國行政區劃通史·三國兩晉南朝卷（下）》南朝陳實州郡縣沿革、所附後梁與王琳政區沿革，以及第十編侨州郡县考表。

南陳部分為 OCR 初步結構化資料。原書本身亦說明陳代州郡縣屬輯考，僅得其涯略；因此網頁以 `※` 標記年代或辨字存疑。後續人工覆核可直接修改底層資料，不必改動前端。

### 南陳方鎮長官

- 魯力《魏晉南北朝方鎮年表新編·宋齊梁陳卷》，上海古籍出版社，2023年。
- 使用其中「陳方鎮年表」558—588年逐年州條：年表以年為經、州為緯，州下列都督、刺史等長官，並附官銜、月份、遷轉與史料考證。
- 本頁只把方鎮資料附著到同年可對應的南陳州；若南陳政區表無該州，另列「方鎮表另見之州」，不自動附著到後梁、王琳政區，也不因此自動增加行政區劃。

### 南陳封爵

參照維基百科：

- 南朝藩王列表
- 南朝公爵列表
- 南朝侯爵列表
- 南朝開國侯列表（功臣）
- 南朝伯爵列表
- 南朝子爵列表
- 南朝男爵列表

封爵資料只是制度注記。南朝封君通常不到封國，網頁不以爵國名稱反推實際行政機構；只有本年能唯一對應一個南陳郡或縣時，才把爵號附在該政區旁。但是，儘管在行政上，封君已經基本喪失了對封國的干預，但封國在制度、禮儀、經濟等諸多層面的實在性確是確定無疑的。因此，我們認為，在唐朝不開國以前，仍有必要在郡縣旁邊標註封國與封君。

### 558—588年地圖

- 558—587年不各自存放一張大型PNG，而是共用`chen-terrain-base-web.webp`，再由`chen-map-dynamic.js`按CHGIS有效年代與網頁年表即時繪製州界、郡界、治所、文字及封國。切換年份不再按31倍增加圖片容量。
- 地圖提供放大、縮小、適合視窗、重設、滾輪縮放和拖曳平移；動態年份可在瀏覽器端匯出2400×2064 PNG。
- 州、郡、縣文字分層避讓；同層文字互相避讓，不同層級可以重疊。封國文字優先於同點行政文字，傳承存疑者仍按封國顯示。

- 588年年表快照共有42州、147郡級政區、578縣級政區及106條有效封國記錄。
- 106條封國全部保存在 `data/chen-map-588.csv`；其中72條取得可靠 CHGIS 坐標並在圖上以紫色封國標記顯示，另34條因無可靠坐標而不臆測位置。28條傳承或本年承襲狀態不明者仍作封國處理，以斜體表示存疑。
- 州郡縣治所與行政界線以 [CHGIS V6](https://dataverse.harvard.edu/dataverse/chgis) 為主；V4補州界、V5補郡界。沒有邊界但有可靠治所坐標者，以治所點承載州、郡資訊；點與邊界均無可靠資料者暫不落圖。
- 政權底色因缺少588年同精度疆域面，暫以 [ChinaXMap 572年北周、北齊、陳疆域](https://www.arcgis.com/home/item.html?id=6b7ce818bd1244d28d414307439b9ddb) 為基礎，將北周、北齊、後梁面溶解為一個統一隋面。它只表示近似政權形勢，不是精確的588年疆域復原。
- 588年吳州不採用CHGIS V4位於鄱陽的同名州記錄；依本頁政區關係，以CHGIS V6吳郡、錢塘郡、吳興郡三面合併重建吳州外界，三郡內界仍保留，州治暫附吳郡治。鄱陽郡仍隸江州。
- 地形為現代靜態高程參考，不是588年歷史地貌復原。
- 588年先載入2400×2064完整預覽；放大至160%或按下「載入588年超高清原圖」後才下載約31 MB的9600×8256原圖。
- `data/chen-map-588.js` 保存559個可與年表穩定ID對應的透明治所熱點。點擊地圖始終可跳到下方文字；文字返回地圖由表格上方的開關控制，預設關閉，且不影響頁碼註釋、封國與方鎮說明。

## 使用與校勘

- 加粗：相較上一年年末發生變動；紅色留作其他類型的信息標記。
- `[1]`：點擊查看書內頁碼、PDF 頁碼與 OCR 摘錄。
- `※`：年代、辨字或推定存疑。
- 下劃線：僑郡或僑縣；點擊右上角註釋可查看侨置考表、「原屬」與人工考證。
- 有色楷體標籤：王國或開國爵資料，點擊仍可查看原有來源、承襲與考據卡片。
- 封爵小字斜體：封君生平、承襲或存續年限在該年缺乏足夠證據，仍保留該封國，但按「存疑規則」顯示。
- 「世子某某服喪」：依本文承襲規則標示的服喪期；若史料明載襲封年份，明文優先。
- 南陳有方鎮資料的州，在州表內顯示「都督/刺史」區塊，每位長官各佔一行；州名與區塊標題均可點擊查看官銜、月份、遷轉及完整考證。
- 南陳年份下拉框使用「年號＋干支＋（公元年份）」顯示；底層計算仍以公元年份作鍵值。
- 明州、利州等正文只知縣而「所領郡乏考」者，左欄標作「郡無考」，不用「州直領」這一後世概念。
