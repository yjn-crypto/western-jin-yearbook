# 南陈地图名称与缩放排版恢复

日期：2026-09-08。

## 回归原因与修正

原实现中，正文已由年度 `displayName` 将附有封国的郡显示为国，地图面标签却直接读取 CHGIS 的固定 `area.n`。因此，同一年可出现正文、治所写“南康国”，面标签仍写“南康郡”的不一致。现在只在同名且治所落在面内、能唯一对应年度正文实体时使用本年名称；参考面没有唯一对应时保留原名，不追加历史判断。

接续的未提交排版改动曾按实体 ID 合并面标签与治所标签，使同一政区只剩一处名字。本轮恢复两种几何标签，均带相同年度国名、封爵信息与稳定 ID。例如南康国的面标签和治所标签均指向 `ch_p0046`。封国文字保持地图既有封国样式，不再绑定持有人姓名颜色。

原来各行政层级分别避让，且避让失败后回填到已占位置，导致同治所及不同层级的名字覆盖。现改为州、郡、县共用碰撞索引；缩放时按屏幕字号重新排版，移位名称用引线回指原位置。地图坐标、边界及行政归属没有改变。

## 显示与导出

- 400% 及以下仅产生州、郡国名称；超过 400% 产生全部州、郡国、县级名称，包括可定位的县级封国。治所圆点继续保留。
- 局部位置放不下的名称排列在底图下方的密集标注区。SVG `viewBox`、页面高度、导出画布同步扩展，避免退到图外后被裁切。地图定位与缩放锚点使用固定地图比例，新增标注区不会改变历史坐标的屏幕位置。
- 候选搜索限制在原位置附近的 12 个行高以内，避免总览密集时逐个搜索整张地图。所有剩余名称仍进入图下列表，不因候选耗尽而丢失。
- “导出当前地图”对 588 年也使用当前动态叠层、缩放对应的名称与完整标注区；原有 588 年人工覆核高清原图下载入口保留。PNG 宽度仍为 2400，增加标注区时只扩展高度，底图不拉伸。

## 一次定点算法检查

用 Node 执行实际年度快照、地图构建与 SVG 节点布局，并核对生成的文字估算框。运行使用 960 像素视口；未进行浏览器、全站或历史资料全量检查。

| 年份与缩放 | 全部名称 | 县级名称 | 南康国面／治所 |
| --- | ---: | ---: | --- |
| 558 年，400% | 707 | 0 | 均存在，ID 均为 `ch_p0046` |
| 558 年，401% | 1894 | 1187 | 均存在，ID 均为 `ch_p0046` |
| 588 年，401% | 1767 | 1251 | 均存在，ID 均为 `ch_p0046` |
| 588 年，100% | 516 | 0 | 均存在，ID 均为 `ch_p0046` |

上述集合运行确认：筛选后的名称数量无遗漏；所有可连接名称的 ID 均来自同一年度已解析实体；文字可通过键盘聚焦；估算框之间无重叠，且均位于扩展后的 SVG 范围内。另以 30 个集中于小范围的标签强制触发退让，全部保留，最下方文字位于 1220、扩展高度为 1234，没有底部裁切。

集合检查暴露了全图候选搜索的性能问题：Node 环境下 588 年总览运行约 18 秒。随后仅对候选生成器增加局部半径上限，并做小例复核与语法检查；每个标签的候选数量限制在 400 以下。此优化不改变名称集合、碰撞判定或图下保留路径，但最终地理位置／图下列表的分配会与上表集合运行时有所不同；未重复整套布局检查。

文字尺寸采用与布局相同的保守估算，检查不等于真实浏览器字体度量或 PNG 解码验收。本轮没有修改原始政区、封爵、沿革、坐标及边界资料；检查完成后统一随本次修正提交。
