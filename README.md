### 南陳地方長官

- 唯一歷史主表為 `master_officials_final.xlsx` 的「任次主表」。生成器只消費其中既有結構化任期邊界、逐年在任錨點及人工裁決，不從史料文字新推任期，也不修改主表。
- 官員年度記錄表示該公元年內可確認或推定曾任，不要求十二月末仍在任。已確定未履任的21條排除；502條原始任次、原始備份、證據映射、人工裁決、第六階段修訂與舊決策均在可追溯來源快照中保留。
- `annual_presence_status` 與 `tenure_boundary_status` 分離。明確年度在任錨點即使任期邊界未知，也以confirmed顯示；可能在任者以probable斜體顯示。
- 郡級與縣級長官分別按 `state_id + prefecture_id` 及 `state_id + prefecture_id + county_id` 精確連接行政快照，禁止名稱回退。无法唯一连接的年度记录仍在独立区展示。

### 557—588年地圖

- 557年只新增疆域圖入口，不反向補造行政資料；558—588年共用`chen-terrain-base-web.webp`，再由`chen-map-dynamic.js`按CHGIS有效年代與網頁年表即時繪製州界、郡界、治所、文字及封國。
- 地圖提供100%—1000%縮放、適合視窗、重設、滾輪縮放、拖曳及方向鍵平移。可在瀏覽器端匯出寬2400像素的PNG，保留當前縮放層級可見的文字及選中高亮；高度依地圖與圖下密集標注區調整。
- 低於300%只顯示州名，300%—700%（含兩端）顯示州、郡名，超過700%顯示州、郡、縣全部名稱；封國按所屬行政層級同步顯示。當前可見的各層文字共同避讓，移位名稱以引線連到原位置，過密時列於圖下；封國文字優先於同點行政文字，傳承存疑者以斜體顯示。
- 點擊地圖名稱或治所會持續高亮對應文字、位置與引線；點選尚未顯示名稱的治所時，自動放大到對應層級。普通模式下，已與本年政區唯一連接的標記會同時定位到正文；未唯一連接的參考標記只在地圖內高亮。
- 「讀圖模式」使地圖佔滿視窗，點擊時保留地圖視野；選中已連接正文的政區後，可按「查看正文」退出並定位年表，或按Escape退出。進出讀圖模式保留縮放、圖中位置與選中狀態。正文返回地圖由表格上方的開關控制，預設關閉；頁碼註釋、封國與方鎮說明仍使用各自入口。
- `data/chen-territories.geojson`採CRS84（WGS84經緯度）保存史圖館分期疆域。年份對應為：557→557、558→559、559→559、560→560、561→561、562→562；573→575、574→575、575→575、576→577、577→577、578→578、579→579。網頁會明示本年圖或最近年份圖；沒有分期矢量的年份仍使用ChinaXMap 572年斷面近似。
- 太建元年（569）史圖館原圖以綠色表示廣州叛亂。GIS中先依同一海陸掩膜裁去叛亂色塊落入珠江口的3837個海面像素，再把陸上叛亂區併回陳朝疆域，並另存`kind=rebellion`的叛亂面；網頁以綠色虛線層疊加，從而同時表達「仍屬陳境」與「正在叛亂」。

- 配準後只在海岸帶用`chen-terrain-base-web.webp`的海陸掩膜校準東南海岸；內陸政權界仍保留史圖館原圖判讀。海南依史圖館歸屬判斷，但島形取自同一經緯底圖的獨立陸地分量，因而不與雷州半島黏連，瓊州海峽保持為水域；臺灣亦有專項排除驗證。這是底圖描摹成果，不把像素邊界宣稱為精確測量疆界；生成流程保存在`scripts/build-chen-territories.py`。

- 588年年表快照共有42州、147郡級政區、578縣級政區及106條有效封國記錄。
- 588年人工覆核原圖的106條封國記錄保存在 `data/chen-map-588.csv`；其中72條取得可靠 CHGIS 坐標並在原圖上以紫色封國標記顯示，另34條因無可靠坐標而不臆測位置。28條傳承或本年承襲狀態不明者仍作封國處理，以斜體表示存疑。
- 州郡縣治所與行政界線以 [CHGIS V6](https://dataverse.harvard.edu/dataverse/chgis) 為主；V4補州界、V5補郡界。沒有邊界但有可靠治所坐標者，以治所點承載州、郡資訊；點與邊界均無可靠資料者暫不落圖。
- 政權底色因缺少588年同精度疆域面，暫以 [ChinaXMap 572年北周、北齊、陳疆域](https://www.arcgis.com/home/item.html?id=6b7ce818bd1244d28d414307439b9ddb) 為基礎，將北周、北齊、後梁面溶解為一個統一隋面。它只表示近似政權形勢，不是精確的588年疆域復原。
- 588年吳州不採用CHGIS V4位於鄱陽的同名州記錄；依本頁政區關係，以CHGIS V6吳郡、錢塘郡、吳興郡三面合併重建吳州外界，三郡內界仍保留，州治暫附吳郡治。鄱陽郡仍隸江州。
- 地形為現代靜態高程參考，不是588年歷史地貌復原。
- 588年與其他南陳年份使用相同的動態圖層和文字分層規則；9600×8256人工覆核原圖保留為獨立下載，不隨縮放載入或取代當前圖層。
- 當前年份的地圖熱點由行政快照與CHGIS治所即時匹配，以當年政區原ID連接正文；郡／國顯示名變化不改ID及坐標。`data/chen-map-588.js`保留原靜態圖559個治所熱點資料供追溯。

## 使用與校勘

- 加粗：相較上一年年末發生變動；紅色留作其他類型的信息標記。
- `[1]`：點擊查看書內頁碼、PDF 頁碼與 OCR 摘錄。
- `※`：年代、辨字或推定存疑。
- 下劃線：僑郡或僑縣；點擊右上角註釋可查看侨置考表頁碼。
- 有色楷體標籤：王國或開國爵資料，點擊仍可查看原有來源、承襲與考據卡片。
- 封爵小字斜體：封君生平、承襲或存續年限在該年缺乏足夠證據，仍保留該封國，但按「存疑規則」顯示。
- 「世子某某服喪」：依本文承襲規則標示的服喪期；若史料明載襲封年份，明文優先。
- `{1}`：本年有可點擊方鎮資料的州；依當年州序從1重新編號，只有有資料者顯示，篩選不改變年度編號。索引、州名與「都督/刺史」區塊標題均可查看官銜、月份、遷轉及完整考證；蕭梁、南陳使用同一規則，西晉不顯示此索引。
- `地方長官`：本年內可確認或推定曾任的郡、縣長官；confirmed正常字體，probable斜體。點擊「人名＋官職」先查看完整官銜、時間、史料原文與考證，ID及追溯碼默認折疊。
- `某某國`：蕭梁、南陳本年附有封國的郡級政區之逐年顯示名；仍可用原「某某郡」檢索，地圖與文字以原穩定ID聯動，不把展示名變化誤作行政沿革。
- 南陳年份下拉框使用「年號＋干支＋（公元年份）」顯示；底層計算仍以公元年份作鍵值。
- 明州、利州等正文只知縣而「所領郡乏考」者，左欄標作「郡無考」，不用「州直領」這一後世概念。
