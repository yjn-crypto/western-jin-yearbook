# 289、308年晋域内漏色的归属处理

本次试验以已经配准到WGS84的史图馆年末政权面约束晋域，再把当年有效的郡、县所属关系接入。政权范围与州郡范围分开处理：其他政权面优先排除，不因补齐郡面而归入西晋；视频晋域内的漏色部位才附给当年仍有效的郡。原有年度数据、289/308原版地图不改写。

旧图中白色同时承担了不同含义。以原版行政轮廓减去此前年度郡面，289年有57个留下缺口的参照区：仍有效郡的几何衔接缺口合计3.797平方度，原始图未命名或待定区合计9.258平方度，没有已失陷或本年无郡期段的缺口。308年有67个参照区：仍有效郡的几何缺口11.898平方度、本年未列父郡的原郡范围6.131平方度、控制规则剔除的失地4.701平方度、原始图未命名或待定区8.970平方度。这些数字是WGS84平方度，只有同坐标下几何前后对照的意义，不能当作实际领土面积。

289年较明显的漏色包括南康、桂林、临海、北地、广陵及南郡。它们的对应郡在年表中仍有有效期，缺口来自旧图轮廓、CHGIS郡面或县拟合的接缝，不能解释为其他政权。308年的永昌还受到“局部控制”筛选影响；汉嘉、西河、雁门及新兴没有当年有效父郡期段；平阳、广汉及蜀则另有失陷规则。新试验由视频中的政权范围区分两种情况：落在晋域内的缺口附给仍有效郡，落在其他政权中的区域保留白色和政权边界。

附属顺序如下：

1. 内部县拟合单元的当年父郡关系有依据时，优先使用该关系；县拟合面和县界不公开显示。
2. 原图对应郡本年仍有效、且没有县父郡分歧时，缺口附回同郡。
3. 参照区内可定位县的当年父郡不同，使用县治位置分区并合入各父郡。此分区只是生成郡界的几何方法，不是历史县界。
4. 原郡本年不列、原图待定或无可定位县时，优先选择本年同州的邻郡；没有可用州属时，附给最近仍有效郡。

每一块新增范围都有所属郡、方法、面积和“推定”标记，并写入逐年补齐报告。全部州面及封国面随后由成员郡重新合并。这样晋域不会因资料缺项而漏色，也不会把不明确的归属包装成已考证的郡界。它仍受视频截图的投影、配准及色块识别误差影响；行政边界的精度不可能高于这些输入。

政权层另外区分中国州郡所在的主晋范围和视频另画的西域都护名义范围。真实其他政权优先排除；名义附属范围如果和主晋相交，则以主晋优先，只在主晋之外另画米黄色，避免把河西晋域误剪成白色。名义附属范围不会为了补齐地图而附给敦煌等中国郡。

完整、自包含的WGS84 GeoJSON存于本机 `work/jin-video/final-gis/289.geojson` 和 `308.geojson`。网页使用公开JSON几何目录，共用郡面和郡界、州面和州界、单郡封国等重复几何；坐标采用6位小数及保持拓扑的精度处理，每个几何分片小于600KB。它们是浏览器加载目录，不能把尚未展开几何引用的JSON当作GeoJSON交付。图像配准误差远大于这一步小于米级的坐标精度处理。
