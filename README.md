# 西晋年末州郡县表

这是一个可直接部署到 GitHub Pages 的纯静态网页原型。用户选择公元 266-316 年中的某一年，页面按州输出该年年末的郡国与所辖县级政区。

## 当前数据范围

- 沿革材料：`《中国行政区划通史·三国两晋南朝卷（上）》`书页 592-765。
- 太康二年（281）断面：书页 766-775，作为优先基准。
- 书中 304 年断面暂未用于本版。

原 PDF 为扫描图像，本版数据由 OCR 初录后生成。281 年断面优先采用断代表；其他年份依据沿革章节中的存续区间重建，尚需逐条校勘。因此本项目定位为**研究原型**，不是可直接引用的最终定本。

## 显示规则

- 普通郡县使用宋体类字体。
- 郡级或县级封国在名称明确带有“国、王国、公国、侯国”时使用楷体类字体。
- 区间的起始年或终止年标红，作为“本年发生变化”的校勘提示。
- 书中只精确到年份时，当前暂按区间终年仍有效显示。

## 本地使用

直接双击 `index.html` 即可打开。数据通过普通 `<script>` 文件加载，不依赖服务器，也没有 API 密钥。

## 部署到 GitHub Pages

1. 新建 GitHub 仓库。
2. 上传本目录中的全部文件。
3. 打开仓库 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，保存。
