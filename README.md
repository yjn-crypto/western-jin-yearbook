# 西晉年末州郡縣表：五等爵封國版

這是一個可直接部署到 GitHub Pages 的純靜態網頁。使用者選擇公元 266—316 年中的某一年後，頁面依原書順序按州列出該年年末的郡國及其所轄縣級政區，並把西晉宗室王國和公、侯、伯、子、男五等爵封國疊加到同一年度斷面中。

本版保留原有前端配色、字體、表格結構和響應式版面，只修改底層資料、年度排序規則和封國注記。

## 本版完成的修改

### 1. 304 年人工覆核改入底層資料

使用者覆核的 76 組 OCR 辨字問題已寫入 `data/jin-data.js`。名稱修正不是只針對 304 年畫面，而是修改同一政區實體的各個有效階段，因此其他年份也會同步使用正確名稱。

### 2. 修正「未知終年只顯示一年」的結構問題

舊抽取器把 `297—？` 等條目錯誤轉成起訖同年，導致一郡只領一、二縣時常在後續年份顯示空白。本版把終年不詳條目暫作延續至西晉資料集末年 316 年，並保留 `※`，表示這是存續推定而不是確定終年。

304 年現在可正常顯示：

- 東安國：蓋、東安；
- 淮陵國：司吾、徐；
- 堂邑郡：堂邑；
- 太原國：盂、狼孟等縣。

### 3. 304 年治所次序

年度排序支援 `order_overrides`。304 年按人工覆核顯示：

- 廣陵郡：射陽居首；
- 南平郡：江安居首；
- 毗陵郡：毗陵居首。

這三項只作用於 304 年，不擅自改動其他年份的原書次序。

### 4. 五等爵封國資料層

新增 `data/five-rank-fiefs.js`，資料參考：

- 維基百科〈晉朝公爵列表〉；
- 維基百科〈晉朝侯爵列表（五等爵）〉；
- 維基百科〈晉朝伯爵列表〉；
- 維基百科〈晉朝子爵列表〉；
- 維基百科〈晉朝男爵列表〉。

顯示方式：

- 郡公、郡侯：標於相應郡級政區右側；
- 公、侯、伯、子、男封國：標於相應縣級政區右側；
- 有可直接匹配封君年份者，顯示封君姓名；
- 封國存續可推定但承襲年份不完整者，列出可能封君並標「推定」；
- 五等爵不計算「元年、二年」；宗室王國仍保留國主年次；
- 點擊小字可查看封爵類型、封君序列、起訖說明及來源頁。

### 5. 同名與制度限制

咸熙、西晉初部分五等縣爵的國名不一定採用實際縣名，也不一定納入郡縣行政體系。本版因此採取保守匹配：只有在所選年份，該封國名稱能唯一對應到網頁中的一個有效郡級或縣級政區時，才自動顯示。存在同年同名異地而不能唯一定位的資料，不附會到任何一處。

## 史料與補充資料的分工

- 州、郡、縣的存在、名稱、隸屬、原書次序和年度區間：依《中國行政區劃通史·三國兩晉南朝卷（上）》書內第 592—765 頁。
- 宗室王國國主及在位年次：參考維基百科〈晉朝藩王列表〉。
- 公侯伯子男封國、封君及起訖：參考上述五個五等爵列表。
- 使用者人工覆核的辨字與 304 年排列：作為高於 OCR 文字層的校勘資料保存。

維基資料只增加分封制度注記，不改寫原書的州郡縣隸屬關係。

## 年末計算口徑

網頁遵循原書本編凡例的年度折算方式：

1. 建置發生在某年上半年，以該年為起始年；發生在下半年，以次年為起始年。
2. 罷廢發生在某年上半年，以上一年為終止年；發生在下半年，以該年為終止年。
3. 僅知發生於某年而不明月份者，新置自該年起算；省廢以該年的前一年為終止年。
4. 郡縣封國以封國之年為起始年，以徙封或省廢之年的前一年為終止年。

頁面顯示的是某年最後一日已生效的行政區劃。

## 上傳到原 GitHub 倉庫

1. 解壓 ZIP。
2. 打開原來的 GitHub 倉庫。
3. 點擊 `Add file → Upload files`。
4. 將解壓後資料夾內的全部內容拖入上傳區。
5. 確認新增了 `data/five-rank-fiefs.js`，並覆蓋其餘同名檔案。
6. 提交到 `main` 分支。
7. 等待 GitHub Pages 重新部署，必要時按 `Ctrl + F5` 強制刷新。

## 公開使用注意

本倉庫不包含原書 PDF，只包含結構化資料、必要的短篇證據摘錄和補充爵位表資料。公開發布時應保留資料來源說明。維基百科內容的再利用應遵守其頁面所示授權條款。
