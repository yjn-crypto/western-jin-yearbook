# 西晋289、308年视频GIS测验与新旧图比较

本轮先完成289、308年：使用本机史图馆视频中本年度最后事件后、下年淡化前的最后清晰地图，配准为WGS84政权面；再与年表的当年州郡县隶属接合。266—316年共51张最后清晰原帧已提取，均保留源视频、原生PTS、帧号和SHA256。其它年份本轮提供可选原幀底图，未宣称已全部重建其GIS行政边界。

公开检索未找到作者明确公布的原始投影。本次用15个海岸、岛屿和治所控制点比较模型：经纬仿射的留一误差15.980像素，墨卡托17.670像素，Albers候选4.408像素。采用中央经线105°、标准纬线25°与47°的Albers候选加仿射，输出再转为WGS84。训练误差3.512像素，最大控制点残差5.651像素。这是对视频画布的配准推定，北方和西北外推范围仍有较大不确定性，不能据此声称历史疆界达到该精度。详见[配准依据](jin-video-projection-research.md)。

## 白洞的原因与处理

289年原图范围内有57个空缺区段，主要是原图未命名范围与CHGIS／原图面接合缺口，没有因本年废郡造成的同类缺口。南康、桂林、临海、北地、广陵等有效郡的缺面，不能表现成非晋领土。

308年有67个空缺区段，混合了有效郡缺面、部分控制时整郡收缩、原表缺项和真正的敌域。永昌的部分控制裁切产生了较大的几何缺口；汉嘉、西河、雁门、新兴等旧控制规则与县的年末记录不完全衔接。平阳、广汉、蜀的失陷白区则不能一概补成晋色。对这些情况，现先用用户指定的视频政权界区分，再处理晋境内的行政归属。

补齐顺序为本年县属约束、仍有效的原郡参考区、带年表父郡的治所分区、同州邻郡、最近有效郡。县域仅参与内部拟合，不公开展示县面或县界。新增部分保留`completion_inferred`及方法记录；无直接证据的分界仍属拟合。其它政权优先于晋色；西域名义附属范围的手描外框与主晋范围交叠时，以主晋范围优先，其余附属范围不附入中国州郡。

新图的全部新增覆盖须分为两种。289年在旧图示意轮廓内补漏12.908平方度，视频晋域超出旧图轮廓的新增50.953平方度；308年相应为15.786和28.529平方度。这些数值仅为WGS84坐标几何对照，不能当作实际平方公里或精确历史面积；不能把视频新增轮廓都说成原图内部白洞。

## 两年结果

### 289年

旧图的白洞主要来自原图未定名区及CHGIS／原图郡面接合，并非本年废郡。本次将视频划定的晋域连续分配给当年有效郡；北方、西北及海岸与旧图有轮廓差异。其它政权另列白色范围，西域名义范围单列。

| 项目 | 结果 |
| --- | --- |
| 视频晋域内旧郡面覆盖 | 84.15% → 补齐后约100%（几何覆盖率，非史料考定率） |
| 晋境内漏色 | 已补齐；不足一个画面像素的计算余量不计为可见漏色 |
| 新图保留的制度着色 | 42个郡级及以上封国面 |
| 当前晋域行政图面 | 17州面、171郡面、948县治点；县界不展示 |
| 视频政治范围 | 18个政权／部族／名义范围，含西晋 |
| 归属推定 | 按本年县属、仍有效原郡、同州邻郡、最近有效郡依次补齐；缺证分界保留推定标记 |

### 308年

旧图把失陷、部分控制收缩、有效郡缺面及未定名区混在同一种空白里。本次明确显示汉、成及五苓夷起兵范围，晋境内缺面继续按本年郡属补齐。视频与旧失陷规则冲突的地方按用户指定的视频政权界绘制，并保留冲突记录；不能把整个宁州并入成。

| 项目 | 结果 |
| --- | --- |
| 视频晋域内旧郡面覆盖 | 87.12% → 补齐后约100%（几何覆盖率，非史料考定率） |
| 晋境内漏色 | 已补齐；不足一个画面像素的计算余量不计为可见漏色 |
| 新图保留的制度着色 | 37个郡级及以上封国面 |
| 当前晋域行政图面 | 20州面、175郡面、871县治点；县界不展示 |
| 视频政治范围 | 26个政权／部族／名义范围，含西晋 |
| 归属推定 | 按本年县属、仍有效原郡、同州邻郡、最近有效郡依次补齐；缺证分界保留推定标记 |

两年政权与晋面无正面积交叠；郡面无越出所选晋域、无相互重叠。289年剩余未覆盖量约2×10⁻⁹平方度，308年为0，均无可见漏色区。上述检查是本轮数据可运行的必要几何检查，并非朝代历史审核。
