县表统计中的“654个可投射时段、647条县记录”，指通过工作簿县属与时间检查的输入。还须满足当年的郡存在、隶州及地域匹配，不能直接把647当成页面挂接总数。在502—557的56年中，578条县记录至少有一年成功挂接，166条尚未在任何一年成功挂接。以535年为例，正文显示495条县记录，另有226段候选或待核记录；后者**不表示这些县该年确定存在**。这些数量也不等于历史上实际县总数，原始表本身可能含异名或重复候选。

## 本轮处理的具体边界

- **海盐549年**同时列于吴郡、武原郡；548年只列吴郡，550年只列武原郡。州郡层按年末处理：549年七月吴郡移属吴州，因此549年的两郡均列吴州。武原郡在原吴州表的549年已经存在，扬州表的550年是返属时间，不是建郡年。
- **富春、临江**依据《梁书》卷56侯景传太清三年十一月，改为549年始见。保存侯景所置的政治背景，不用它断言梁廷实际控制。
- **决口／临水529年**同时显示旧名、新名；湖熟535年省废当年保留，536年撤出；昆山535年始列，不提前。
- **新安郡梁安**遵照人工表从527年展示，同时保留527／535年代争议。这个显示起点不升级为无争议建县年。
- **谢征南兰陵太守**只显示534、536两个有证据的年度，不插入535年。广晋令王筠与同名文士使用不同人物身份，刘潜的卒年也不从刘遵的死亡记载误移。

## 使用口径与现存限制

县保留各时段和人工备注，按“县随郡”呈现；人工仅定位到州的5条不造郡名。原文为“暂系”“暂取”的记录及其“同上”继承仍明确标为暂定。同名郡有多个候选时不取第一项；县考地域和州郡表分区不一致时也先保留待考，例如湘滨、重华与巴陵郡的沅湘／江汉分区差异。

官员记录表示本年有授官或在任证据，与州郡年末状态有别。〔授官〕只确认任命，没有独立到任证据；已见在任事迹而到郡日未详者，也在详情中说明。尚不能连接的6条年度记录涉及南梁、巴西、吴兴、兰陵、南兰陵；例如555年吴兴改置震州，旧政区底表没有可挂接的吴兴郡行，此时保留裴之横的在任证据，不因缺郡而删除其官历。

方镇的1010条是**机械来源对齐成功数**，不是1010条任期已经完成历史考定。原书首年列全朝州名、末年集中年不详人物的体例必须保留。现有同名大州匹配仍沿用既有项目的连续性和所辖郡数规则，未来应逐条升级为有来源的实体连接。

侨置目前仍以旧底表为基础，只完成出处层和两处明确误配的修正。○、△、无标表示梁陈两朝的存在关系，不足以证明某一年的存续；尚缺的南琅邪、彭城、南东海等侨郡或双头郡，需要补建实体和具体时段。本轮没有把全部侨置表转换成逐年行政事实。

封爵制度已完成研究，但本轮未重写全部萧梁封爵任次。继承现有展示时，仍应区分授封、追封、世子、袭封及服丧，不据父卒自动立嗣，不据封号反推行政长官。地图仍只有534、555两个参考断面，不代表逐年的准确边界。

## 验证

- 工作簿：87条人工确认及备注逐格保留；10处“同上”可追溯；753段起止与源表相符；33项源工作簿边界检查通过；重复导入输出逐字节一致。
- 县显示：执行页面实际快照，遍历全部56年，验证有效时段、地域、郡名、重复项及上述海盐、决口／临水、湖熟、昆山、梁安边界；5条仅州线索不挂郡。
- 原典：独立XML解析EPUB核验80处短引、卷次、章节、物理段落、逻辑段号、字符偏移及书籍哈希，全部通过。见[引文验证](liang-epub-evidence-verification.json)。这项检查证明转录定位一致，不代替历史判断。
- 长官与来源：29任次／30年度、24挂接／6待定位、仅授官标记、谢征不插值、方镇摘要不改写、15页侨注定位均通过。
- 陈代回归：原任次数据完整性检查、588补订、最终人物与封爵显示、方镇索引与历史官衔、梁陈原年表、人物颜色、来源注释、地图读图检查通过。原陈代数据文件未作修改。
- 浏览器：已核验刘潜检索与原文弹窗、张齐天门太守〔授官〕、549海盐双郡、湘潭待考入口、切回588陈代和陈祗合并双郡任官；测试页未报脚本错误。

## 重建方法

输入原书、工作簿和全量抽取语料留在本机；版本库保存选出的研究数据、来源定位及脚本。Node脚本无额外依赖；县导入需Python `openpyxl`，非macOS名称转换另需OpenCC。

```sh
python3 scripts/import-liang-county-review.py /path/to/蕭梁未確認縣郡歸屬_機器複核.xlsx
python3 scripts/import-liang-governor-sources.py /path/to/15366762.pdf_by_PaddleOCR-VL-1.6.json
python3 scripts/import-liang-qiao-pages.py /path/to/中国行政区划通史：三国两晋南朝卷Ⅱ\(1\).pdf_by_PaddleOCR-VL-1.6.json
python3 scripts/verify-liang-epub-evidence.py --source-dir /path/to/epubs
node scripts/build-liang-local-officials.mjs
node scripts/validate-liang-county-display.mjs
node scripts/validate-liang-first-round.mjs
```

`data/liang-officials-reviewed.json` 是本轮经逐条审校的输入；关键词候选只能供下一轮研究，不能自动覆盖这份审校结果。
