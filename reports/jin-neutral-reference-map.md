# 西晋年度地图：无色政区参考层

本次只调整地图阅读方式，年度西晋郡面、疆域筛选、多郡王国合并数据均保持原样。县域拟合单元继续在内部生成郡界；地图不再显示县面和县界。失地及未衔接区域增加无色州郡轮廓、郡名和县治参考，不能据此认定它们在本年仍归西晋。

原来的白洞来自三类处理：

1. 年度生成器把 `lost / external / enemy / withdrawn` 政区从西晋范围剔除，并从同年 CHGIS 郡面减去失陷县的拟合单元，防止邻郡将失地重新吞入西晋。广汉自301年、成都自303年，以及洛阳311年后的空白属于这类军事控制筛选。孙吴对峙时期的外部排除可以保留；西晋后期腹地用白洞表达则丢失了行政地理背景。
2. 年表郡的有效期结束后，生成器只合并仍列入本年的父郡及县。有效期结束既可能表示失陷，也可能来自沿革表的记录口径，不能直接等同“正式撤郡”。还有父子期段冲突，例如上洛郡止于311年而丰阳、拒阳县期段延至316年；原书正文又说两县曾旋废。这类源表不一致应保留地理参考，不能凭空认定仍有该郡，也不应成为阅读上的白洞。
3. 原图郡面与同年 CHGIS 郡面的轮廓不同、原图存在待定复合区域，以及部分县治无法定位，会在多源拼接时留下未覆盖区。它们不是新的政权边界，也不能仅凭空白判断废置。

新层的绘法是：以289或308年的原图郡面作为地理参照，减去本年度已经绘制的郡面，剩余区域只绘灰色轮廓、名称与治所；不添加封国颜色，不改动本年西晋范围，不计入本年的州郡县统计，也不建立有效政区链接。参考名称有本年有效期时采用当年名称；没有时采用原郡基础名称，并在提示中注明参考年份与本年未列原因。未定位县仍留在表格中，不补造坐标。

280年以前不加入孙吴内部背景，晋吴分属的江夏、建平、庐江也不借无色层补回吴方全郡。宁州、湘州、江州、秦州、平州尚未设立或暂时并省时，参考州名归入当时母州，避免把后期州名提前画出。

数据采用共享要素目录及按年加载的几何分片，避免每次打开一个早期年份都下载所有晚期失地范围。其用途是保持行政地理背景可读；精确政权边界仍待后续接入用户选定的史图馆资料。
