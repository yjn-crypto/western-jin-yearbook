# 南陳地圖文字分層與正文連接修正

日期：2026-09-07。

## 顯示修改

- 縮放 400% 及以下只显示州、郡國名稱；超過 400% 顯示州、郡國及縣名。治所圓點保留。
- 原先避讓失敗而直接略去的文字改為保留，在超過 400% 時顯示；密集地點仍可能重疊，未移動實際治所坐標。
- 588 年網頁改用既有年度向量資料與共用地形底圖，讓縣名也能按縮放分層。588 年人工覆核 PNG、CSV 與下載入口保留。
- 封國地圖名稱使用正文相同的年度持有人配色函數。同一標籤含多個持有人且顏色不一致時保留原色。

## 點擊不到正文的結構原因及處理

1. 原有地名文字禁用了指針事件，只能點治所坐標上的小圓。文字避讓後與圓點分離，點名稱沒有反應。現在可對應的名称本身也能用滑鼠或鍵盤定位正文。
2. 多個政區共用坐標時，圓形熱區互相遮擋。現在每個已連接政區各自保留可點名稱，且名稱畫在熱區上方。未改動坐標或行政歸屬。
3. 地圖原始 CHGIS 資料還包括未在本年正文收錄的參考政區；它們沒有合法的正文目標。現在點這類名稱會顯示「未與本年正文唯一連接」說明，不另行補配同名縣。
4. 588 年原流程將文字烘焙於 PNG，與一份靜態熱區清單分開維護；舊程式遇到本年正文沒有的 ID 仍保留該熱區。现在统一从本年正文生成可連接政區，使用同一套向量文字與正文 ID。
5. 原封國替代標籤按坐標整組隱藏普通地名，同坐標但不同名稱的政區可能一併消失。現在替代條件同時包含政區層級、坐標與既有政區名稱。

## 範圍與待統一驗收

僅修改地圖顯示與連接結構；未修改原始政區、地圖坐標、沿革或史料資料檔案。仍沿用原有坐標解析方式；缺乏坐標或唯一正文對應的參考點不新增歷史判定。

按使用者要求，本輪未新增或反覆運行地圖測試、瀏覽器驗收或雜湊檢查。400% 分層、588 年顯示、重疊標籤及正文定位留待陳代整體驗收。
