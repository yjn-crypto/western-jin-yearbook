# 西晉年末州郡縣表

這是一個可直接部署至 GitHub Pages 的純靜態網頁。使用者選擇公元 266—316 年中的某一年後，頁面按州列出該年年末的郡、郡級封國及其所轄縣級政區。目前的问题主要是OCR精度不够，暂时还不支持学术使用。

## 本版更新

- 全部介面、政區名稱與來源摘錄改為繁體中文。
- 重新使用帶文字層的 OCR 版《中國行政區劃通史·三國兩晉南朝卷（上）》抽取資料，不再沿用上一版的低品質 OCR 結果。
- 州、州內各郡、郡內各縣均依原書的敘述次序顯示，不按拼音、名稱或存續年代另行排序。
- 相較上一年年末發生變動的州、郡、縣以紅色標示。
- 每一年的變動註釋由 `[1]` 重新起算。點擊右上角的中括號數字，可查看書內頁碼、PDF 頁碼與相關 OCR 校訂摘錄。
- 保留原有頁面的配色、字體、表格結構與響應式版面；封國仍使用楷體類字體，普通郡縣仍使用宋體類字體。

## 資料範圍

- 主要沿革材料：《中國行政區劃通史·三國兩晉南朝卷（上）》書內第 592—765 頁。
- 對應 OCR PDF 頁碼約為第 619—792 頁，兩者相差 27 頁。
- 年份範圍：公元 266—316 年。
- 網頁不包含原 PDF，也不需要伺服器、資料庫或 API。

本版依新 OCR 文字重新抽取並對若干罕見地名作了人工覆核，但仍屬可持續校勘的研究資料。原書年代本身帶有「前」「後」「？」等限定，或 OCR 仍有待確認的條目，會以 `※` 標示。

## 年末計算口徑

網頁遵循原書「本編凡例」的年度折算方式：

1. 建置發生在某年上半年，以該年為起始年；發生在下半年，以次年為起始年。
2. 罷廢發生在某年上半年，以上一年為終止年；發生在下半年，以該年為終止年。
3. 僅知發生於某年而不明月份者，新置自該年起算；省廢以該年的前一年為終止年。
4. 郡縣封國以封國之年為起始年，以徙封或省廢之年的前一年為終止年。

因此，頁面不是顯示某年任意時點，而是重建該年最後一日已生效的行政區劃。凡在該年發生且至年末已生效的變化，都應反映在該年的結果中。

## 顯示符號

- **紅色文字**：相較上一年年末發生新置、復置、廢省、改名、改屬或所轄政區變動。
- **`[1]`、`[2]`……**：本年度的變動註釋。每次切換年份均從 1 重新編號，點擊可查看依據。
- **`※`**：不是原書符號，也不是「雪花」。它是上一版網頁加入的校勘標記，表示年代或文字仍帶不確定性。
- **楷體類字體**：郡級或縣級封國。
- **宋體類字體**：一般州、郡、縣及其他行政單位。

被廢除或轉出的政區不會繼續出現在年末表格中，但會列入「本年變動索引」，並提供相應註釋。
公元 266 年是本資料集的基準年；因未納入 265 年完整快照，該年不以空白資料作比較，也不把全部政區誤標為新增。

## 原文次序

資料檔為每個層級保存獨立的 `order` 欄位：

- 各州依原書西晉沿革章節的次序排列；
- 州內郡國依原書的編號及出現次序排列；
- 郡內縣級政區依原書列舉次序排列。

前端只依 `order` 排序，不會自行按名稱重排。這可保留原書通常將州治所在郡、郡治所在縣置於前列的編排資訊。

## 本地使用

解壓後直接雙擊 `index.html` 即可打開。資料由普通 JavaScript 檔案載入，因此不需要本地伺服器。

## 部署至 GitHub Pages

1. 在 GitHub 新建一個公開倉庫。
2. 將本資料夾內的全部內容上傳到倉庫根目錄；請勿只上傳 ZIP。
3. 確認 `index.html` 直接位於倉庫根目錄。
4. 進入 `Settings → Pages`。
5. 在 `Build and deployment` 中選擇 `Deploy from a branch`。
6. Branch 選擇 `main`，資料夾選擇 `/ (root)`，然後儲存。

## 目錄結構

```text
western-jin-yearbook/
├─ index.html
├─ style.css
├─ app.js
├─ README.md
└─ data/
   ├─ jin-data.js
   └─ source-meta.json
```

## 資料結構與註釋

`data/jin-data.js` 內保存：

- 州、郡、縣的穩定識別碼；
- 原書次序；
- 各名稱與隸屬關係的有效年份區間；
- 不確定性標記；
- 書內頁碼、PDF 頁碼與短篇來源摘錄。

頁面先計算所選年份與上一年的年末快照，再比較兩個快照。變動註釋由當年可見政區依原書次序編號，隨後再編列本年已廢除或轉出的政區。

## 公開使用注意

本倉庫只放置結構化研究資料與必要的短篇證據摘錄，不放置原書 PDF。公開發布時應在頁面保留書名與資料來源說明，並避免把原書全文或大段掃描頁面一併上傳。
