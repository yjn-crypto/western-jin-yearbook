# 梁代人物姓名與封君規則：本輪修改

本輪只補人物顯示與封君選擇的共用規則，不改陳代身份資料，不覆寫既有梁代人物年度色，也不處理長史、司馬原工作簿格式。共享介面由主線接入。

## 已實作

- `liang-fief-rules.js`：所有候選人都先檢查每一側已知年代。吳平侯蕭昺起年未詳、止於523年，不會在535年再被後備邏輯選出。追封者保留在歷史資料，但不作在任封君；多名無界候選不按陣列先後取第一個。相鄰年相差三年不再自動生成「世子服喪」，須有明確年度、服喪標記及出處。
- `liang-person-formats.js`：地方官、刺史、封君使用同一姓名名錄、明列繁簡字及字面爵號別名。姓名不必在當年刺史色表出現才能被辨認；日期與官職不納入姓名色。已知非蕭姓人物依梁代異姓綠色規則顯示，蕭姓無當年身份資料者保留黑色並說明待核。
- `data/liang-person-evidence.js`：補《梁書》卷22所見蕭宏、蕭秀、蕭偉、蕭恢、蕭憺五位皇弟及卒年的有界證據，補蕭機520—528年襲安成王證據。保留蕭子顯南齊宗室身份出處，未將其直接套入梁帝近親色。新增張齊502年安昌侯、留異556年永興侯兩項授封單年證據；沒有填滿後續持爵年份。
- 爵號可來自本輪原典證據，或既有梁封爵表中具明確起止、非存疑、非追封的封君時段。若改封當年有兩項爵號，不替研究者決定先後；未知起年不補成502年。

## 本次有限檢查

執行 `scripts/validate-liang-person-rules.mjs`，發現並補足「异／異」轉換後通過；沒有跑全專案回歸或建立分支。

- 502—557年既有封爵資料中，2047個有返回封君的年度情況均未越過已知起止界，也未把追封者當在任。
- 640項既有梁代人物年度色逐項保持原值。
- 本輪開始時的30条地方官年度记录全部可識別，29条有姓名色；537年蕭子顯保留黑色，原因為梁代年度身份色未定。不是把所有同姓人物自動視作宗室。
- 專項確認蕭昺535年不選出、無證三年空檔不自動服喪、同年多名無界候選不選第一人、張齊單年授封不外推、蕭偉518年改封不擅選爵號、官職及月日不被姓名匹配吸收。
- 15項本機《梁書》短引文實例依段落ID及字元位置核對成功，引用中保存卷次、EPUB內文件、段落ID及原檔校驗值。

以上為本輪必要的資料與規則檢查；頁面實際載入、共用函式接線及瀏覽器結果由主線整合時另記。

## 接入 API

載入依賴：既有梁人物色表、梁封爵表、梁地方官資料 → `data/liang-person-evidence.js` → `liang-fief-rules.js` → `liang-person-formats.js`。

- `LIANG_FIEF_RULES.resolveHolder(record, year)`：返回 `{status, holder, prev, next, candidates, posthumous, source, reason}`。沒有可选封君時 `holder:null`，不虛構人名；既有介面可繼續顯示「封君存疑」。`posthumous`只供歷史說明，不作活躍封君。
- `LIANG_PERSON_FORMATS.matches(text, year)`：返回 `index/length/text/person/yearStyle`，同時有 `start/end/style/colorStyle/color/source/displayName`。
- `displayName(person, year)`：返回 `text/title/canonicalName/source/pending`，部分有原典 `evidence`。
- `decorateText(text, year)`：僅為裸姓名補有據爵號，已有明列爵號時保留原文，日期及官職保持原樣。
- `personStyle(person, year)`、`fiefStyle(personOrRecord, year)`、`fiefRecordStyle(matchOrRecord, year)`：可分別給姓名及整個封國框套用顏色；來源與待核原因可放在懸浮說明。無具名活躍封君時不替全框猜色。

## 保留待考

- 既有梁刺史色表個別年度可能與傳記身份存在差異，本輪依指令保留原色，不把補證擴成全表重寫。
- 所有持爵不完整、授封年份未詳、年內改封次序未明者繼續保留原姓名或存疑封君；沒有根據三年差創造服喪或承襲年。
- 部分既有封爵時段仍來自彙編列表；本輪加入的原典證據不足以代表全部封君已重新考訂。
