# 萧梁郡县长官：EPUB 首轮研究记录

本轮读取用户在 Downloads 提供的《梁书》《陈书》EPUB，以原典建立可追溯候选库，并精校首批 29 任次、30 个年度见载锚。其中6条仅有明确纪年的任命证据，独立保留为 `appointment_only`，不能据此宣称当年已经抵任。首批是研究样本，不代表两书任官记载已经处理完毕。

候选是召回用索引，包含中央官职、祖先仕历、前官、封爵或“令”字命令句等误报，不能直接变成任次。完整段落和候选留在本机 `work/epub/`。版本库只需要短引精校数据和提取、验证脚本，不需要上传 EPUB 或全书抽取文本。

运行：

```sh
python3 scripts/extract-liang-official-candidates.py --source-dir ~/Downloads
python3 scripts/verify-liang-epub-evidence.py --source-dir ~/Downloads
```

提取器使用标准库 HTMLParser，验证器独立使用 XML 事件解析。验证器直接读 EPUB 核验书籍哈希、卷次、TOC 章节、章节段号、HTML 文件段号及引文字符起止位置；不以先前抽取 JSON 自证。正式数据为 `data/liang-officials-reviewed.json`，三郡建置证据为 `data/liang-geography-reviewed.json`。验证报告中的数据文件路径使用仓库相对路径。原典字符与定位核验不能代替对任职和年代的历史判断。

正式精校数据已纳入独立审校。`work/epub/build_reviewed_officials.py`只保留初次选录过程，不能重新运行后覆盖正式数据，否则会撤销6条任命状态、萧子显卒年精度及王志后官证据等审校修正。

## 数据口径

首批数据包含 `records` 与 `excluded` 两个集合。各任次保留原文地点、规范职名、完整官衔、人名及别名，单列 `annual_presence_years`。页面只显示这些已精校年度，不把任次起止边界展开成连续任期，也不做前后各三年的窗口推算。

- `dated_in_office_attestation`：明确年份的事件中以现任地方官称之，如 505 年吴兴太守柳恽，550 年衡阳内史周弘直。
- `dated_appointment`：明确年份任命。另有任事叙述者保留 `appointment_with_service_context`，但不由后来的任事叙述倒推当年的抵任日；缺少独立履任证据者单列 `appointment_only`。
- `dated_death_in_office`：本年明确以该职遇害或卒官，如 535 年广晋令王筠。
- 同年同郡可有不止一人：例如 555 年义兴太守韦载、陈拟，保留各自证据，不据同名地点直接排除一人，也不声称两人年末同时在任。
- 谢征南兰陵太守有 534 年出任、536 年卒官双锚，首批仅显示两个年度，535 年不自动补齐。

6条 `appointment_only` 分别为张齐天门太守（503）、柳忱南郡太守（503）、陈拟义兴太守（555）、袁枢吴兴太守（556）、王志南郡太守（507）、王志江夏太守（508）。这些是任命年份见载，不与已证在任事件混同。萧子显537年出任并到吴兴有证据，但“至郡未几，卒”没有单独卒年，正式数据已撤除推定的精确537卒年。

“梁书/陈书收录”不是朝代判断。孙谦钱唐令记于“齐初”，须排除于梁；任昉中央官秘书监不属于郡县长官。内史可为地方正长官，但王侯封号本身不能生成地方官，例如留异的永兴县侯不等于永兴县令。

## 已识别的审校风险

1. **未履任作用域。** 程灵洗吴兴太守“未行”、沈恪永嘉太守“不拜”、张齐新兴永宁二郡太守“未发而卒”、乐法才南康内史“辞不拜”均明确排除。张齐在“虎贲中郎将。未拜，迁天门太守”中的未拜修饰前一中央官；袁枢的给事黄门侍郎未拜也不能越过多年仕历扩展到吴兴太守。
2. **前官。** 550 年祖皓称“前江都令”，只证此时已经离任，不能当550年在任锚。
3. **主语切换。** 沈顗传“其年卒于家”指沈顗，不能算给同段出现的太守柳恽；刘遵卒后太子写给阳羡令刘孝仪的信，卒者不是收件人刘孝仪。
4. **同名异人。** 535 年遇害的广晋令王筠不能与梁末文士王筠按姓名合并。本条使用专门人物 ID。刘孝仪则经本传明确“刘潜，字孝仪”合并为刘潜，保留刘孝仪别名。
5. **副职与摄任。** 庾荜“会稽郡丞、行郡府事”应另存郡丞兼摄任，不直接改称会稽太守。本轮正长官发布样本未收入。
6. **原文地名。** 程灵洗兰陵太守未擅加“南”字，冯道根南梁太守未误配成南梁州。地点 ID 须按年份与建置证据独立匹配；同名郡不能选择搜索结果第一条。
7. **底本文字问题。** EPUB 中可见异体、缺字及个别纪年异常，自动抽取保留原文。比如陆襄鄱阳内史“七年”的上下文存在再核必要，首批没有用该年建立起任锚；广晋令王筠则由明确大同元年事件直接建立535锚。

## 三郡 549 年始置的独立证据

《梁书》卷五十六《列传第五十·侯景》：

|郡|始置时间|原文短引|本地定位|
|---|---|---|---|
|武原郡|549 年六月|“景乃分吴郡海盐、胥浦二县为武原郡。”|`LS-C58-P0075`；`OEBPS/text00005.html` 第75段|
|临江郡|549 年十一月|“景以钱塘为临江郡，富阳为富春郡。”|`LS-C58-P0079`；同文件第79段|
|富春郡|549 年十一月|同上|同上|

该传 `LS-C58-P0070` 的“五月，高祖崩于文德殿”属549年；此后记六月、十一月建郡，到 `LS-C58-P0082` 才进入“大宝元年正月”（550）。因此三郡均有549年始置的独立原典证据。建置主体是侯景，表述宜保留这一政治背景。证据存于正式文件 `data/liang-geography-reviewed.json`，不需要由县归属裁决反推郡建置。

与现有政区底表比对后，武原郡在549年的吴州记录中原已存在，其550年记录表示返属扬州，不能把550误读为该郡第一次设置，也不能称三郡的旧起年均错。本轮校正的是富春、临江两郡起年为549。吴郡549年按年末政区口径列于吴州；年内分县置郡的事件与年末所属州分别记录。

## 后续人工资料需求

当前不需要用户逐条重抄这两部纪传，EPUB 原文已能批量抽取。后续最有价值的人工输入是：

- 若有针对梁代郡县长官的既有手工考证，请提供原表及裁决说明，特别是同名异人、同名郡、除授未到任与摄任的处理依据。
- 若已指定某一底本、点校版或勘误表，请说明版本；本轮首批短引可先独立工作，但全量研究遇到缺字、异名或纪年异文时需要底本交叉核校。
- 对于人工县表中的待定同名县，优先提供对应原书页码或截图及已有推理，而不只提供最终归属，以便连入地方官证据链。

这些是继续提高精度需要的辅助资料，不妨碍现有29任次及其明确证据先行接入页面。
