# 西晉年末州郡縣表：封國制度版

這是一個可直接部署到 GitHub Pages 的純靜態網頁。使用者選擇公元 266—316 年中的某一年後，頁面依原書順序按州列出該年年末的郡國及其所轄縣級政區。本版在不改變原有前端配色、字體、表格結構和響應式版面的前提下，增強了封國制度的展示。

## 本版新增內容

1. 修正「僅領一縣的郡未顯示縣」問題：
   - 冀州中丘郡補入中丘縣；
   - 幽州昌黎郡補入昌黎縣；
   - 涼州西海郡補入居延縣；
   - 徐州堂邑郡補入堂邑縣。
2. 郡級封國右側以小字顯示所選年份的國主及年次，例如「東安王司馬繇之四年」。
3. 國主年次參考維基百科〈晉朝藩王列表〉；依該表所列初封、改封、復封年份起算。若同一國同一年有前後兩位國主，因網頁顯示年末狀態，採該年後起者。
4. 若同名封國在所選年份無法與藩王表唯一匹配，顯示「國主未詳」，不自行補造。
5. 縣級政區的條文若明見「公相、侯相、伯相、子相、男相」，在縣名旁以小一號字標示「公國、侯國、伯國、子國、男國」。點擊可查看書內頁碼、PDF 頁碼和原文摘錄。
6. 本書若未明載縣級封國的起訖年或國主姓名，網頁只保留封國等級提示，不把推測寫成確定資料。

## 為何堂邑郡原先沒有堂邑縣

原抽取器主要識別「1.某縣、2.某縣」這種帶阿拉伯數字序號的縣條。原書在一郡僅領一縣時，常直接寫縣名而省略序號。例如堂邑郡條在說明「可考者唯有堂邑一縣」後，直接列「堂邑（304—316）」。舊抽取器識別到堂邑郡，卻沒有把無序號的堂邑縣轉成縣級資料。因此這是資料抽取規則的結構性遺漏，不是年末計算邏輯造成的。

## 史料與補充資料的分工

- 州、郡、縣的存在、名稱、隸屬、順序和年度區間：依《中國行政區劃通史·三國兩晉南朝卷（上）》書內第 592—765 頁。
- 郡級及縣級王國的國主、在位起訖和年次：參考維基百科〈晉朝藩王列表〉。
- 縣級五等封國等級：只在本書相應縣條明見「某公相、某侯相、某伯相、某子相、某男相」等文字時標示。

維基資料只作國主與年次補充，不改寫原書的政區沿革。兩者不一致或無法匹配時，網頁顯示「國主未詳」。

## 年末計算口徑

網頁遵循原書本編凡例的年度折算方式：

1. 建置發生在某年上半年，以該年為起始年；發生在下半年，以次年為起始年。
2. 罷廢發生在某年上半年，以上一年為終止年；發生在下半年，以該年為終止年。
3. 僅知發生於某年而不明月份者，新置自該年起算；省廢以該年的前一年為終止年。
4. 郡縣封國以封國之年為起始年，以徙封或省廢之年的前一年為終止年。

因此頁面顯示的是某年最後一日已生效的行政區劃，而不是該年任意時點。

## 顯示符號

- **楷體類字體**：封國。
- **小字「某王之某年」**：所選年份的國主年次，點擊可查看計算依據。
- **小字「公國、侯國、伯國、子國、男國」**：本書條文所見的縣級五等封國提示，點擊可查看原文。
- **紅色文字**：相較上一年年末發生變動。
- **`[1]`、`[2]`……**：本年度變動註釋，每年重新編號。
- **`※`**：網頁校勘標記，表示年代或辨字存疑，不是原書符號。

## 上傳到原 GitHub 倉庫

1. 解壓 ZIP。
2. 打開原來的 GitHub 倉庫。
3. 點擊 `Add file → Upload files`。
4. 將解壓後資料夾內的 `index.html`、`style.css`、`app.js`、`README.md` 和整個 `data` 資料夾拖入上傳區。
5. 確認新增了 `data/princes.js`，並覆蓋其餘同名檔案。
6. 提交到 `main` 分支。
7. 等待 GitHub Pages 重新部署，必要時用 `Ctrl + F5` 強制刷新。

## 公開使用注意

本倉庫不包含原書 PDF，只包含結構化資料、必要的短篇證據摘錄和補充藩王表資料。公開發布時應保留資料來源說明。維基百科內容應依其頁面所示授權條款使用與署名。
